# 📌 Overview

**LovableDebate** is an AI-powered debate coach that simulates realistic debates using multiple intelligent agents.

Unlike traditional chatbots that simply answer questions, LovableDebate actively challenges your opinions, presents counterarguments, verifies facts through Retrieval-Augmented Generation (RAG), and evaluates every debate using specialized AI judges.

Whether you're preparing for interviews, courtroom arguments, UPSC discussions, Model UN, classroom debates, or public speaking, LovableDebate provides real-time coaching and actionable feedback.

## ⚖️ Six-Agent Judging Pipeline

Every debate is evaluated independently.

| Judge | Responsibility |
|---------|----------------|
| Logic Judge | Logical consistency |
| Evidence Judge | Supporting facts |
| Rebuttal Judge | Counterarguments |
| Communication Judge | Clarity & fluency |
| Persuasion Judge | Convincing ability |
| Moderator Judge | Final score aggregation |
